Sentinel Auth API

외부 클라이언트가 토큰 인증, 기기 관리, 버전 확인, 파일 다운로드를 수행하는 REST API입니다.
모든 응답은 JSON이며 (다운로드 제외), 에러는 공통 형식으로 반환됩니다.

Base URL: /api/v1/auth
인증 방식 — 대부분의 엔드포인트는 X-Client-Id 헤더(앱 식별자)와 쿼리 파라미터 token을 요구합니다. 토큰의 maxDeviceCount가 0보다 크면 X-Device-Id 헤더(Windows Machine GUID)가 추가로 필요합니다.
인증
POST /api/v1/auth/login/token 토큰 로그인 + 기기 등록 + 이력 기록

토큰 유효성 검사와 함께 기기를 등록하고 LoginHistory에 요청을 기록합니다. 클라이언트 프로그램 최초 실행 시 호출합니다.

Headers

이름필수설명
X-Client-Id필수앱 식별자 (App.appId)
X-Device-Id조건부maxDeviceCount > 0일 때 필수. Windows Machine GUID.

Query Parameters

이름필수설명
token필수검사할 토큰 문자열

Responses

200 OK 
{
  "tokenStr": "abc123...",
  "appName": "My App",
  "expireDate": "2026-12-31",
  "maxDeviceCount": 1
}

cURL

curl -X POST "https://HOST/api/v1/auth/login/token?token=YOUR_TOKEN" \
  -H "X-Client-Id: app_12345678" \
  -H "X-Device-Id: 12345678-ABCD-..."
POST /api/v1/auth/check/token 토큰/기기 유효성 주기 확인 (이력 미기록)

프로그램 구동 중 주기적으로 호출하여 토큰/기기 상태를 확인합니다. LoginHistory에 기록하지 않으며, 등록된 기기의 lastSeenAt만 갱신합니다.
기기가 로그아웃되었거나 등록이 없으면 DEVICE_LOGGED_OUT을 반환하므로 클라이언트는 이때 프로그램을 종료해야 합니다.

X-Device-Id선택등록된 기기 확인 시 사용

GET /api/v1/auth/download 최신 파일 다운로드 (스트리밍)

등록된 최신 파일을 application/octet-stream으로 스트리밍합니다. 응답 헤더로 버전과 체크섬을 같이 전달하니 다운로드 후 검증에 사용하세요.

Response Headers

이름설명
Content-Dispositionattachment; filename="..." (원본 파일명)
Content-Length파일 크기 (bytes)
X-File-Version버전 문자열
X-File-SHA256SHA-256 체크섬 (64자 hex)

cURL

curl -o myapp.exe \
  -H "X-Client-Id: app_12345678" \
  "https://HOST/api/v1/auth/download?token=YOUR_TOKEN"
GET /api/v1/auth/download/{version} 특정 버전 파일 다운로드

버전을 지정하여 해당 파일을 다운로드합니다. 응답 헤더는 /download와 동일.
